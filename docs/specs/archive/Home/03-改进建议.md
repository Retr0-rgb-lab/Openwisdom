## 1. 现状评分（动效维）

| 维度 | 评价 |
|------|------|
| Spec 08 对齐 | **高** — MUST 齐、NEVER 净、Heavy 3/3 可解释 |
| 品牌一致性 | **中高** — 场+三形+主色；Harness 仍偏「信任带」 |
| 性能/全局场 | **中** — DotField 全站 rAF，非 Home 也跑 |

## 2. 优先改进（P0–P3）

### P0 — 正确性 / 规范硬伤

| ID | 问题 | 建议 | 动效/库影响 |
|----|------|------|-------------|
| **H-P0-1** | Spec C7：JS 失败时内容应 **opacity=1**；BlurText 初始仍有 **blur+0.18** | 默认 CSS `opacity:1; filter:none`，仅在 `document.documentElement.classList` 有 `js-motion` 时启用 initial；或 hydration 后 `initial={false}` | 改 `BlurText` / `Reveal` / `StaggerItem`，**不**引新库 |
| **H-P0-2** | Spec：BlurText **locale 不重播**；现三实例每次 remount 重放 | session/locale 级 `hasPlayed`；或单组件内三行一次树 | BlurText 行为 |
| **H-P0-3** | DotField 挂 **全站**，Spec 表写「Hero 场」 | Home：慢漂；其它路由：`static` 或卸载 rAF；`visibilitychange` 暂停 | DotField / SiteBackdrop |

### P1 — 体验与性能

| ID | 问题 | 建议 | 来源候选 |
|----|------|------|----------|
| **H-P1-1** | Model：Section **Reveal** + 箭头 **whileInView** 双重入场 | 去掉箭头 enter，只保留 280ms 换卡 | — |
| **H-P1-2** | 入场双标准：Reveal vs 未用的 `.ow-view-enter` | 文档锁定「网格 Stagger / 段落 Reveal」**或** 段落迁 CSS view-timeline（RM 已写 opacity 1） | 现有 `globals.css` |
| **H-P1-3** | Spotlight 只靠 CSS `motion-reduce:hidden`，指针状态仍更新 | `useReducedMotion` 短路 pointer handler | SpotlightCard |
| **H-P1-4** | Heavy 已满 3/3，无余量 | 新环境层前必须 **降级** LogoLoop→静态 或 DotField→static | — |
| **H-P1-5** | ClickSpark + toast 双反馈 | 可保留；火花时长 ≤450ms；非 emphasis 安装可关火花 | ClickSpark |

### P2 — 表达 / 产品对象

## 3. 「用什么 / 从哪来」— 改进落地时的标注规范

以后任何 Home 动效 PR 必须在 PR 描述或本目录增补表中写清：

```markdown
| 表面 | 效果 | 库/来源 | 文件 | Heavy? | RM |
|------|------|---------|------|--------|-----|
| Hero | … | React Bits X 改编 / motion / CSS | path | Y/N | … |
```

**来源标签枚举：**

- `react-bits:<name>` — 上游组件名  
- `motion` — motion/react  
- `css` — keyframes / view-timeline / tw-animate  
- `ow-custom` — 自研

## 4. 建议实施顺序（无代码承诺，仅计划）

```text
Wave 1（规范）
  H-P0-1 C7 floors → opacity 1 default
  H-P0-2 BlurText once / no locale replay
  H-P0-3 DotField per-route static + pause when hidden

Wave 2（干净）
  H-P1-1 Model 去箭头 enter
  H-P1-2 锁定入场策略文档 + 可选 view-timeline
  H-P1-3 Spotlight RM 短路

Wave 3（表达）
  H-P2-1 skill 物件 snippet
  H-P2-5 文档/二级 install 链接
  仅当预算释放后考虑 H-P3-*
```
