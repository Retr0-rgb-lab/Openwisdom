## EN（主推）

```
Start with Openwisdom (MIT):

1. Browse → https://openwisdom.vercel.app
2. Install → npx openwisdom install macro-scan
3. Or wire MCP → npx -y openwisdom-mcp
4. Invoke the skill in your agent

Contribute: fork → write SKILL.md → open a PR.
github.com/Retr0-rgb-lab/Openwisdom
```
