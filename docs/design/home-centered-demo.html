场景 Skills

三个场景，三种定位动作

每个场景是一条可执行的分析流程：何时使用、分步提问、输出结构、偏见检查点。

macro-scan

宏观扫描

01 / 03
整体视角

把一个局势、行业或系统拆成结构：行动者、激励、约束与趋势。

何时用 · 面对复杂局面，需要先看清全貌再做判断时。

  1. 界定局势边界与时间尺度
  2. 识别行动者、激励与约束
  3. 输出可检验的结构与趋势图

引用 政治学、经济学、社会学

在目录中查看
personal-anchor

个人锚点

02 / 03
个体视角

把个人处境放进历史与社会的坐标：你在哪条曲线上，脚下是哪一层。

何时用 · 做长期选择——职业、城市、方向——想知道自己身处何处时。

引用 历史学、社会学

在目录中查看
metacognition-audit

元认知体检

03 / 03
结构视角

给一次思考做体检：暴露偏见、盲点与证据缺口，而不是给结论抛光。

何时用 · 重要结论形成之后、落地之前，想检验思考质量时。

引用 心理学
