## 1. 产品三表面（已实现）

| 表面 | 路径 | 角色 | 状态 |
|------|------|------|------|
| **Web** | `apps/web` | 双语目录站：发现 / 筛选 / 详情 / 安装指引 / 贡献 | Home + Skills + Install/Docs/Contribute **实页** |
| **CLI** | `packages/cli` (`openwisdom`) | 人用包管理：search / list / install / update | **npm 0.1.0+**（`npx openwisdom`）；monorepo + **skills-snapshot 离线**仍可用 |
| **MCP** | `packages/mcp` (`openwisdom-mcp`) | Agent stdio 工具，同语义 | **npm 0.1.0+**（`npx -y openwisdom-mcp`）；catalog-snapshot 已 dual-write |
| **Core** | `packages/core` | 共享 install / catalog / telemetry 客户端 | 无 TTY / 无 process.exit |

**硬边界（不变）：** 无托管分析对话；CLI/MCP **不调 LLM**；无 `run` 分析命令。

## 2. 内容与 catalog 真相

```text
skills/**/SKILL.md
  → packages/schema 校验
  → packages/catalog build
  → catalog.json + manifest.json
       ├─ packages/{catalog,cli,core,mcp}/…-snapshot
       └─ apps/web/public/registry/
```

| 层 | 当前规模（2026-07-30 audit-close 后） |
|----|----------------------------------------|
| Official scenarios | 3：`macro-scan` · `personal-anchor` · `metacognition-audit` |
| Official references | 5：五学科理论卡片（path-dependence 等） |
| Community on disk | 0（目录壳就绪） |
| 机器 catalog skillCount | **8** |
| Web 发现层 | registry 可安装 + curated-external 发现种子（诚实分面） |

**Web 合并规则（audit-close 01）：**

1. `public/registry/catalog.json` → `source: "catalog"`（可安装真相）  
2. bootstrap overlay 丰富 UI（when/steps）且保留 catalog 源  
3. curated seeds → `provenance: "curated-external"`，`installMode: "link-only"`  
4. Source 筛选：Official | Community | Curated（community **不含** curated）

**载荷安装优先级（core）：**  
`OPENWISDOM_SKILLS_ROOT` → monorepo `skills/` → package `skills-snapshot/`

## 3. Monorepo 包图

```text
@openwisdom/schema
@openwisdom/providers  → harness 路径表
@openwisdom/catalog    → build 脚本
@openwisdom/core       → install / catalog load / telemetry client
openwisdom (cli)       → citty + clack
openwisdom-mcp         → MCP SDK stdio
web                    → Next.js 16 App Router
```

Root scripts：`dev` · `build` · `test` · `catalog:build` · `cli` · `mcp`
