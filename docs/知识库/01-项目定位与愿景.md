# 项目定位与愿景

## 一句话

**Openwisdom** 是开源的社会科学 Agent Skills 库 + 成熟双语目录官网 + 跨主流 Coding Agent 的技能包管理 CLI：帮助人用心理学、社会学、历史学、政治学、经济学等框架做宏观分析，理清自身在历史洪流中的锚点，并提升元认知。

## 核心价值主张

| 目标 | 含义 |
|------|------|
| 宏观分析 | 用社科框架（结构、趋势、权力、资源、制度、文化等）分析处境与局势 |
| 历史锚点 | 帮助用户理解「我此刻处于怎样的历史/社会坐标」 |
| 元认知 | 暴露推理偏见、视角盲区、证据缺口，提升「思考自己如何思考」的能力 |
| 开源社区 | GitHub 为真相源；官方与社区分层；网页引导贡献 |

## 学科覆盖（内容域）

- 心理学（Psychology）
- 社会学（Sociology）
- 历史学（History）
- 政治学（Political Science）
- 经济学（Economics）

学科内容以 **reference（理论/方法卡片）** 形式沉淀，由 **场景 skill** 在流程中引用（见决策记录中的分层模型 D）。

## 产品三件套

1. **GitHub 开源仓库** — skills 源码、规范、PR 贡献、版本历史  
2. **网页（技能目录站）** — 发现、筛选、详情、下载、贡献指引；中英界面；对标成熟产品官网  
3. **Openwisdom CLI** — 技能包管理器（search / install / update / list）；交互选择安装到哪些 Agent  

## 明确的非目标（v1 不做）

| 非目标 | 原因 |
|--------|------|
| 网页内嵌完整 AI 对话分析台 | 分析在用户自己的 Agent 中运行；避免模型费用、鉴权与产品线发散 |
| CLI 自建模型调用层 | CLI 只做安装与管理，不 `run` 出分析结果 |
| 网页自建上传后端 / 账号收藏（v1） | 贡献走 GitHub PR；降低后端与滥用治理成本 |
| 强制每份 skill 双语正文 | 正文语言以贡献者为准；站点 UI 双语即可 |

## 目标用户（工作假设）

- 已使用 Claude Code、Cursor、Codex、Grok 等 coding agent 的知识工作者  
- 希望用结构化社科框架做处境/局势分析、自我定位与元认知练习的人  
- 愿意通过 GitHub 贡献 skill / reference 的开源协作者  

（用户画像可在后续设计中细化，但不改变 v1 形态。）

## 成功的直观标准

用户可以：

1. 在官网上理解 Openwisdom 是什么，并用一键/一条命令开始安装；  
2. 浏览官方三大场景 skill 与五大学科 reference，下载或 CLI 安装到所选 Agent；  
3. 在自己的 Agent 里调用场景 skill，完成一次宏观分析 / 锚点梳理 / 元认知审视；  
4. 按网页贡献指南与仓库模板，通过 PR 向 `community/` 提交新 skill 或 reference。
