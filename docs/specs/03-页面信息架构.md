## 1. IA 原则

1. **双心智：** 落地页讲清「是什么、为何装」；Skills 是「图书馆」。  
2. **分层内容：** 场景 skill（可调用流程）+ 学科 reference（理论卡片）。  
3. **安装优先：** CLI 一命令是主 CTA；网页下载 / GitHub 为辅。  
4. **分析在用户 Agent：** 站点不托管对话。  
5. **官方 / 社区：** 筛选与徽章清晰，信任可感知。  
6. **UI 双语 · 正文随贡献语言。**  
7. **热度可见：** 目录/详情展示 skill 安装热度（网页下载 + CLI 安装成功）；默认排序仍 featured，可选按热度。

## 2. 站点地图

所有用户页：`/{locale}/…`，`locale ∈ {zh, en}`（**建议双前缀**）。

### P0（v1 必须）

| 路由 | 角色 |
|------|------|
| `/{locale}/` | 叙事首页 |
| `/{locale}/skills` | Skills 目录（主导航图书馆） |
| `/{locale}/skills/{slug}` | 详情（scenario 与 reference **统一**） |
| `/{locale}/install` | 安装中枢 |
| `/{locale}/docs` | 文档首页 |
| `/{locale}/docs/getting-started` | 首次成功路径 |
| `/{locale}/docs/faq` | FAQ |
| `/{locale}/contribute` | 贡献引导 → GitHub PR |
| `/{locale}/about` | 使命与非目标 |
| 本地化 404 | 恢复路径 |

### P1（同发布若产能允许）

| 路由 | 角色 |
|------|------|
| `/{locale}/disciplines` | 五大学科枢纽 |
| `/{locale}/disciplines/{discipline}` | 单学科库 |
| `/{locale}/docs/concepts` | 场景 vs reference；运行边界 |
| `/{locale}/docs/cli` | search/install/update/list |
| `/{locale}/docs/agents` | Harness 路径矩阵 |
| `/{locale}/docs/skill-spec` 等 | 编写规范 |
| `/{locale}/docs/changelog` 或 `/changelog` | 版本 |

### v1 明确不做的页

网页 AI 对话 · 账号/收藏 · 上传审核台 · 定价 · 博客（可后置）

### 机器端点

| 路由 | 角色 |
|------|------|
| `/registry/catalog.json` | CLI/Web 共用索引（无 locale） |

## 4. 逐页规格

### 4.1 首页 `/{locale}/`

| 项 | 内容 |
|----|------|
| **目的** | 60 秒理解产品 + 转化安装 |
| **用户任务** | 懂三大支柱 → 复制 CLI → 进入目录 |
| **模块** | ① Hero（宏观分析 / 历史锚点 / 元认知）+ 安装命令 ② Harness logo 条 ③ 三大场景 skill 卡 ④ 分层示意（场景→reference） ⑤ 五学科入口 ⑥ 安装路径说明 ⑦ official vs community ⑧ 贡献预告 ⑨ 底 CTA |
| **主 CTA** | 复制 `npx openwisdom install` · Browse Skills · Docs · GitHub |
| **空/错** | 索引失败时仍展示静态三场景 + GitHub |
| **SEO** | 本地化一句话 title；OG 含三支柱 |
| **动效** | Hero 克制（见视觉/组件 spec）；列表 stagger 可选 |

### 4.2 目录 `/{locale}/skills`

| 项 | 内容 |
|----|------|
| **目的** | 发现 / 筛选 / 搜索 |
| **模块** | 搜索 · 分面 · 活跃 chip · 排序 · 网格/列表 · 无查询时精选场景 · 分页 |
| **卡片字段** | 标题 · layer · official\|community · 学科 · contentLang · 摘要 · tags · **热度（30d 优先，可悬停看累计）** · 复制安装 |
| **筛选** | 见 §5 |
| **排序** | 默认 `featured`；可选 `popular`（按 installs30d）、`name`、`updated` |
| **空状态** | 清空筛选 + 推荐三场景 + 去贡献；community 为空时解释 PR；stats 不可用时隐藏数字不报错 |
| **SEO** | 规范到裸目录 URL；不索引无限 facet 组合 |

### 4.3 详情 `/{locale}/skills/{slug}`

| 项 | 内容 |
|----|------|
| **目的** | 评估 + 安装 |
| **共用** | 粘性安装条 · Markdown 正文 · 元数据（含 **Installs 30d / Total**）· GitHub · 相关项 |
| **Scenario 专属** | 何时用 · 分步流程 · 输出骨架 · 偏见检查点 · 引用的 references |
| **Reference 专属** | 定义 · 适用边界 · 常见误用 · 引导问题 · 「被哪些场景使用」 |
| **CTA** | CLI 复制 · 下载 zip/raw · 打开 GitHub |
| **SEO** | `{Name} · Scenario\|Reference · Openwisdom` |

### 4.4 安装 `/{locale}/install`

| 项 | 内容 |
|----|------|
| **目的** | Impeccable 密度的安装面 |
| **模块** | 交互式 CLI 说明 · 整包/单 skill 命令 · 手动 zip/clone · Harness 矩阵 · 验证步骤 · update · FAQ 摘要 |
| **边界** | 未支持 Agent → 手动路径 + Issue 模板 |

### 4.5 Docs / Contribute / About / FAQ

| 页 | 要点 |
|----|------|
| Getting started | 安装 → 在*用户* Agent 中跑通 macro-scan |
| Concepts | 分层模型 +「本站不做托管分析」 |
| Contribute | fork → 模板 → **仅 community/** PR；链到 GitHub templates |
| About | 定位、学科、非目标、开源 |
| FAQ | 无网页聊天 · CLI 不调模型 · 文件装哪 · 更新 · 语言策略 · harness 看不到 skill |

### 4.6 学科页（P1）

枢纽展示五科；单科页 = 该科 official references + 引用它们的 scenarios。

## 5. 筛选与搜索

| 分面 | 值 | 控件 |
|------|-----|------|
| Layer | scenario / reference | Toggle / Tabs |
| Source | official / community | Chip |
| Discipline | 五学科 | 多选 |
| Content language | zh / en / … | 多选 |
| Tags | 策划+自由 | P1 可搜 |

**查询串示例：**

```text
/{locale}/skills?layer=scenario&discipline=psychology&source=official&lang=zh&q=…&sort=featured|popular|name|updated
```

| 行为 | 规范 |
|------|------|
| 数据源 | 构建时 `catalog.json` + **运行时/ISR 合并 stats**；浏览不依赖 GitHub API |
| 默认排序 | featured：官方场景 → 官方 reference → 社区（**不**被瞬时热度打乱官方叙事） |
| 热度排序 | `sort=popular` → `installs30d` 降序；并列可用 total 或 id |
| 首屏 | 无硬过滤 |
| 移动 | 筛选 Sheet + 活跃计数 |
| Header 搜索 | 跳 `/{locale}/skills?q=` 或 Command 面板 |
| SEO | 高价值视图可实体化（学科页）；facet 噪音 canonicalize；热度数字 noindex 噪声不单独成页 |

## 6. 内容类型与 URL

| 类型 | URL | 备注 |
|------|-----|------|
| Scenario | `/{locale}/skills/{slug}` | 如 `macro-scan` |
| Reference | 同上 | `layer` 元数据区分 |
| Discipline | `/{locale}/disciplines/{kebab}` | 英文 slug，UI 中英标签 |
| Docs | `/{locale}/docs/...` | 核心文档双语 |

**元数据最小集：**  
`id, slug, layer, scope, disciplines, title, summary, language, tags, version, updated, repoPath, install.cli`  
（UI 可用 `title_zh`/`title_en` 或构建时从 locale 字典补全卡片文案；**正文**仍随 `language`。）

**安装表面（命令名以实现注册为准）：**

```bash
npx openwisdom install
npx openwisdom install macro-scan
npx openwisdom search "metacognition"
npx openwisdom update
npx openwisdom list
```

## 7. 主用户旅程

1. **安装者：** 首页 → Install/CLI → Getting started → Agent 内 macro-scan  
2. **检索者：** Skills → 筛 reference+心理 → 详情 → 相关场景 → 安装  
3. **贡献者：** Contribute → 规范 → GitHub PR → community 可见  
4. **双语：** 落 zh → 切 en（同 slug）；正文 `language` 徽章始终可见  

---

## 8. 实现优先级

1. i18n 壳 + 导航  
2. 首页  
3. 目录 + 分面 + 卡片  
4. 详情（双层类型）  
5. Install  
6. Getting started + FAQ  
7. Contribute + About + 404  
8. Disciplines  
9. CLI/规范/changelog 文档  
10. SEO + a11y 验收
