# 热度与遥测

> 蒸馏自原 Spec 06 · 27–29；产品决策 #11。

---

## 1. 目标与非目标

| 目标 | 说明 |
|------|------|
| 热度信号 | 每 skill 可展示安装/下载热度 |
| 双端采集 | 网页 + CLI/MCP 安装成功 |
| 无账号 | 匿名、聚合、可退出 |
| 不污染内容库 | **不**进 `SKILL.md` / git skills |

**非目标：** 用户画像、广告追踪、强制联网才能安装、个人安装历史。

---

## 2. 事件模型

| `event` | 来源 | 计入主热度 `installs*` | 说明 |
|---------|------|------------------------|------|
| `cli_install_success` | CLI / MCP | **是**（权 1） | 全部选中 provider 写入成功后；多 provider **计 1** |
| `web_download` | Web | **是**（权 1） | zip/SKILL 下载成功（优先服务端 download 路由） |
| `web_copy_install` | Web | **否**（漏斗 `copies*`） | 复制 install 命令 |
| `web_view` | Web | 否 | v1 可不做 |

### Payload（匿名）

```json
{
  "schemaVersion": 1,
  "event": "cli_install_success",
  "skillId": "macro-scan",
  "ts": "2026-07-29T12:00:00.000Z",
  "source": "cli",
  "cliVersion": "0.1.1",
  "sessionId": "optional-uuid",
  "meta": { "providers": ["claude"], "scope": "project" }
}
```

| 禁止入库 | 要求 |
|----------|------|
| 姓名、邮箱、机器名、完整主目录、IP 画像 | `skillId` ∈ catalog 白名单 |

MCP 使用 **同一事件名**，`source: "mcp"`。

### 聚合字段

```json
{
  "macro-scan": {
    "installsTotal": 10,
    "installs30d": 3,
    "cliInstallsTotal": 7,
    "cliInstalls30d": 2,
    "downloadsTotal": 3,
    "downloads30d": 1,
    "copiesTotal": 20,
    "copies30d": 5
  }
}
```

**主排序键：** `installs30d` = cli_install_success + web_download（近 30 天）。  
文案：「安装热度」「Installs (30d)」；热度 ≠ 学术质量。

## 3. 采集点

### Web

| 动作 | 事件 |
|------|------|
| Download（catalog 源） | `web_download`（服务端计数优先） |
| 复制 CLI 成功 | `web_copy_install` |
| curated/无 skill 的全局命令 | **不报** skill 级热度 |

Helper：`reportWebHeat(event, skillId)` — fail-open；sendBeacon / fetch keepalive。

### CLI / MCP

| 规则 | 说明 |
|------|------|
| 时机 | 该 skill 全部目标 provider 成功之后 |
| 方式 | 短超时 fire-and-forget |
| 关闭 | `--no-telemetry` · `OPENWISDOM_NO_TELEMETRY=1` · `CI=true` |
| URL | `OPENWISDOM_TELEMETRY_URL=<site>/api/telemetry` |
| 部分失败 | 该 skill **不上报**（防虚高） |

## 4. API

实现：`apps/web` Route Handlers。

### `POST /api/telemetry`

- 校验 schemaVersion=1 · event 枚举 · skillId 白名单（读 registry）  
- 限流：约 **60 req / IP / min** → 429  
- 存储失败仍 **200/204 ok**（fail-open）  
- CORS：`Allow-Origin: *`（CLI）  

### `GET /api/stats`

```json
{
  "schemaVersion": 1,
  "updatedAt": "…",
  "skills": { "macro-scan": { "installsTotal": …, "installs30d": …, … } }
}
```

- 可选 `?ids=a,b`  
- `Cache-Control: public, s-maxage=300, stale-while-revalidate=60`  
- 空存储 → `skills: {}`，**非**假数字  

### `GET /api/skills/[skillId]/download`

附件下载 + 服务端记 `web_download`（避免双计）。

## 5. HeatStore

| 后端 | 条件 |
|------|------|
| **Memory** | 无 Upstash env（dev/test） |
| **Upstash REST** | env 齐全（生产） |

日桶 key 例：`ow:evt:{yyyy-mm-dd}:{skillId}:{event}` → rollup 30d/total。

路径参考：`apps/web/src/lib/heat/*` · `app/api/telemetry|stats|skills/...`

---

## 6. 前端合并

1. catalog 静态 + `fetchStats`（RSC revalidate ~300s）  
2. `mergeHeat`：有 key 才写 `installs30d` / total  
3. 无数 / 失败：字段 undefined，UI 隐藏；popular 回退 featured  
4. **永不**因遥测阻塞安装/下载  

| UI | 行为 |
|----|------|
| SkillCard | 有 30d 才显示小号热度 |
| sort=popular | 有 heat 才显示选项 |
| 默认 sort | featured |
