## 3. 跨 agent 共识（已写入 specs）

1. **Web = 目录站**，分析在用户 Agent；CLI = 包管理器。  
2. **架构 A**：`skills/` 真相源 → `catalog.json` → Web + CLI + `/registry`。  
3. **视觉 B**：冷场 + 铜色 datum + 衬线思辨；反紫 AI slop。  
4. **IA C**：叙事首页 + Skills 主图书馆；统一 `/skills/{slug}`。  
5. **shadcn 基座 + React Bits 点缀**；Docs 用 Sidebar 模式。  
6. **贡献 B+D**：PR + 网页引导；official/community。  
7. **Contentlayer 避免**；自研 catalog 或 Content Collections。
