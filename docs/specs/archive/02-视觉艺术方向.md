# Openwisdom 视觉艺术方向 Spec

> 状态：草案（待拍板）  
> 日期：2026-07-29  
> 成熟度对标：[impeccable.style](https://impeccable.style/)（完成度，非业务皮肤）  
> 栈：React · Tailwind · shadcn/ui · React Bits（点缀）

---

## 1. 设计原则

1. **表面模式清晰**：落地页 = 说服+阅读；目录 = 操作+阅读；文档 = 阅读。不要一套「SaaS 模板」打天下。  
2. **已承诺的系统**：颜色、字阶、圆角、elevation 写入 token / 后续 `DESIGN.md`。  
3. **层级优先于装饰**：强字号对比、有节奏的留白，少容器嵌套。  
4. **反 slop 即质量门槛**：见 §7 禁令。  
5. **双语原生**：中英混排光学重量、行高、卡片高度均需实测。  

**验收主观题：** 与 impeccable.style 并排，信息密度与精致度是否同属「认真做的产品官网」一档？

## 2. 隐喻评估

| 隐喻 | 与价值对齐 | UI 用法 | 风险 | 结论 |
|------|------------|---------|------|------|
| 坐标 / 图集 | 宏观分析、「我在哪」 | 结构网格、datum 点、索引卡 | 装饰性满屏网格 | **v1 主隐喻** |
| 地层 / 堆叠 | 历史与学科分层 | 分区横带、目录深度 | 变成米色「AI 纸感」 | **次级系统语言** |

| 历史之河 | 时间连续 | 时间线文案 | 浪花动效 kitsch | **仅文案，不作 chrome** |

## 3. 三套艺术方向

### 方向 A — Archival Strata（档案地层）

- **气质：** 当代研究档案；墨水与档案纸；学科如地层。  
- **色：** 纸 `#F4F0E6` · 墨 `#1C1B19` · 页边灰 · 低饱和学科条带。  
- **字：** Source Serif 4 + Noto Serif SC；UI Source Sans 3 + Noto Sans SC。  
- **动效：** 几乎不动；筛选如抽屉。  
- **风险：** 易滑向「米色品味 AI 站」。  

### 方向 B — Instrument of Orientation / 坐标图集（**推荐**）

- **气质：** 精密社科图集；冷场 + 单一铜色 datum；标记「你站在哪」。  
- **色：** 场 `#EEF1F2`（冷灰白，**非暖奶油**）· 墨 `#0E141B` · 线 `#C5CDD4` · **铜 datum `#B87333`** · 洞见绿 `#2F6F6A`。  
- **字：** 思辨标题 Source Serif 4 + Noto Serif SC；UI **IBM Plex Sans** + Noto Sans SC；CLI **IBM Plex Mono**。  
- **母题：** datum 十字 / 针；仅在说明图中用结构网格；技能卡如索引卡顶线。  
- **明暗：** **浅色默认**；暗色为深夜研究室（哑光，无 neon glow）。  
- **风险：** 过度「地图 HUD」——用 token 与审查禁止装饰网格墙纸。  

### 方向 C — River Continuum（河流汇流）

- **气质：** 历史如缓流；学科如支流。  
- **色：** 深水 / 岸沙 / 芦苇绿 / 泥金。  
- **风险：** 自然插画 kitsch；连续流动画破坏信任；**目录操作感弱**。  

---

## 4. v1 推荐：方向 B

| 理由 | 说明 |
|------|------|
| 价值对齐 | 「宏观 / 锚点 / 元认知」都是**定位**行为 |
| 差异化 | 避开紫 AI 与默认暖米色 |
| 双语目录 | 学科 chip、元数据密度友好 |
| 可落地 | shadcn token 映射清晰；React Bits 仅克制入场 |

**备选：** 若团队更偏「图书馆温度」可选 A，但须压冷纸色、拉高对比，避免 cream-slop。

## 5. Design Tokens（方向 B 起点）

```text
--ow-field:         #EEF1F2
--ow-surface:       #FAFBFC
--ow-ink:           #0E141B
--ow-ink-muted:     #4A5560
--ow-line:          #C5CDD4
--ow-datum:         #B87333      /* primary */
--ow-datum-pressed: #8E5520
--ow-insight:       #2F6F6A      /* links / official */
--ow-danger:        #9B2C2C      /* 认知警告，非营销戏剧 */
--ow-community:     #6B5B4F
```

**学科 chip（仅描边或 10% 底，禁止整卡彩虹）：**  
心理 `#7D6B8A` · 社会 `#A67C52` · 历史 `#8B4D3B` · 政治 `#3D4F7C` · 经济 `#3F6B4F`

**规则：** 纯色正文；禁止渐变字；accent 约占视口 ≤5%；品牌族禁止紫/violet。

### 字体

| 角色 | EN | ZH |
|------|----|----|
| Display / 思辨标题 | Source Serif 4（罗马体为主） | Noto Serif SC |
| UI / 导航 / 按钮 | IBM Plex Sans | Noto Sans SC |
| 正文长读 | Source Sans 3 或 Source Serif 4，16–18px，lh 1.55–1.7 | Noto Sans/Serif SC |
| 代码 / 安装命令 | IBM Plex Mono | 同左 + CJK 回退 |

**禁用默认脸：** Inter、Geist、Space Grotesk、Instrument Serif 作为品牌主脸。  
字阶步长 ≥1.25×；正文 measure 约 65–75ch。

### 形状与 elevation

- 圆角：卡片/输入 6–10px；pill 仅小标签  
- 优先发丝线边框，而非大软阴影  
- **禁止** 卡片套卡片、厚侧色条 + 大圆角、玻璃拟态  

### 首页记忆点

单一 **Orientation 图**（坐标场 + 三价值轴或 “you are here” datum）——优先静态 SVG；可选一次性描边动画，**禁止循环**。

## 6. 动效哲学

### 允许

| 对象 | 规格 |
|------|------|
| 焦点环 / 键盘态 | 150–200ms ease-out |
| 筛选结果重排 | opacity + Y 4–8px，200–280ms |
| 复制安装成功 | 勾选替换，无 confetti |
| Sheet/Dialog | opacity + 轻位移，ease-out，无 bounce |
| Hero datum 落位 | **一次** 400–600ms，不循环 |
| `prefers-reduced-motion` | 装饰动效 → 瞬时 |

### 必须静止

正文与主张、背景场与网格、照片/示意图（无 hover 缩放）、导航结构（无跑马灯）。

**原则：** 动效确认**工具动作**或**一次定向品牌**；禁止靠扭动「贩卖智慧」。

---

## 7. 硬禁令（Anti-patterns）

### 色与氛围
紫/青 AI 渐变 · 玻璃拟态 · glow 阴影 · 径向光晕 · 渐变标题字 · 未审视的暖奶油身份色 · 暗色+neon  

### 布局
厚侧边条圆角卡 · 卡中卡 · 六宫格图标墙当唯一首页 · 假数据英雄指标 · 满屏装饰网格 · 超大圆角 blob  

### 字体与 chrome
Inter 全家桶 · 扁平字阶 · 超长多行 hero 句 · 「Introducing…」眉标堆叠 · 默认斜体衬线 startup hero  

### 动效
弹跳弹性对话框 · 自动滚动 logo 海 · 静态状态假脉冲 · 假终端光标 · 粒子/orb 场  

### 文案与品牌
supercharge / unlock potential · 猫头鹰/发光大脑/曼陀罗 · 伪拉丁纹章 · 半中半英 UI · official/community 做成彩虹趣味徽章  

### 产品错位
像聊天产品 · 像金融 dashboard · 像玄学 app
