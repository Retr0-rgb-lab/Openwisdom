## 4. 形态语法

1. **三形：** 圆=宏观 · 方=结构 · 三角=个体/锚点  
2. **网格：** 仅面板内 5×5；禁止满屏 wallpaper grid  
3. **悬浮面板：** 轻阴影 + 发丝线  
4. **圆角：** 6–10px  
5. **禁止：** 厚彩顶条默认卡装饰、卡中卡、紫渐变、玻璃拟态按钮、假社会证明

## 5. 动效技术栈

| 层 | 选型 | 禁止再引入（v1） |
|----|------|------------------|
| Chrome 进出场 | tw-animate-css + shadcn | 第二套 animate 插件 |

## 6. React Bits：MUST / MAY / NEVER

### MUST

| 组件 | 表面 | 要点 |
|------|------|------|
| **DotField** | Home Hero | 低 alpha；无光标凸起；RM=静态 |
| **Noise** | Hero 或极轻全局 | 静态 SVG 3–7%；禁每帧 canvas |
| **BlurText** | Home H1 **一次** | words/CJK；locale 切换不重播 |
| **Reveal** / CSS fade-up | 区块入场 | 默认内容可见 |
| **SpotlightCard** | 场景/技能卡 hover | radial ≤14% alpha |
| **LogoLoop** 或静态 harness | 信任条 | loop ≥36s、hover 暂停、移动=静态 |

### MAY

ShapeGrid（与 DotField 二选一）· 弱 Magnet（主 CTA）· ClickSpark（仅复制成功）· TextType（安装 demo 一次）· AnimatedList · Stepper · CountUp（**仅真实**统计）· TrueFocus  

### NEVER

Hyperspeed · Galaxy · Prism · Aurora · Beams · Lightning · Plasma · LightRays · Orb · PixelBlast · 各类 Cursor Trail · Glitch/Scrambled Text · GooeyNav · Electric Border · Ballpit · Lanyard · GridScan · 每页 >3 重特效 · 循环品牌打字机 · 假指标 CountUp · Silk/Threads/Particles（v1）

## 7. Hero 配方

```text
[bg field]
  [DotField 或 ShapeGrid | HEAVY #1]
  [Noise 静态]
  [可选 5×5 玻璃小面板]
  [eyebrow 静态]
  [H1 BlurText 一次 | HEAVY #2]
  [副文 Fade ≤400ms]
  [InstallCommand 静态为主]
  [Harness: LogoLoop 慢或静态 | 可选 HEAVY #3]
```

**prefers-reduced-motion：** 静态场 + 全文立刻可见 + 无 Blur/Spark。

## 8. 动效宪法

| 规则 | 说明 |
|------|------|
| C1 静内容默认 | 正文/主张/导航不循环扭动 |
| C2 一次入场 | BlurText、reveal：once |
| C3 工具反馈 | 复制/Tab/Sheet：150–250ms |
| C4 环境克制 | DotField 安静可见；可 static |
| C5 LogoLoop | 有条件例外：慢、可关、移动静态 |
| C6 禁喧宾 | 禁止高速 marquee / 多条并行 |
| C7 失败安全 | JS 失败时内容 opacity = 1 |
