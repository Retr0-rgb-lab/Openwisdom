## 1. 产品三表面（已实现）

| 表面 | 路径 | 角色 | 状态 |
|------|------|------|------|
| **Web** | `apps/web` | 双语目录站：发现 / 筛选 / 详情 / 安装 / Docs / 贡献 | Home 6-beat + Skills + Install/Docs/Contribute 实页 |
| **CLI** | `packages/cli` (`openwisdom`) | 人用包管理：search / list / install / update | **npm `0.1.1`**；`npx openwisdom`；skills-snapshot 离线 |
| **MCP** | `packages/mcp` (`openwisdom-mcp`) | Agent stdio 六工具，同语义 | **npm `0.1.2`**；`npx -y openwisdom-mcp` |
| **Core** | `packages/core` | 共享 install / catalog / telemetry | 无 TTY / 无 `process.exit` |

**硬边界（不变）：** 无托管分析对话；CLI/MCP **不调 LLM**；无 `run` 分析命令。

## 2. 内容与 catalog 真相

```text
skills/**/SKILL.md
  → packages/schema 校验
  → packages/catalog build
  → catalog.json + manifest.json
       ├─ packages/{catalog,cli,core,mcp}/…-snapshot
       └─ apps/web/public/registry/
```

| 层 | 当前规模（2026-07-31） |
|----|------------------------|
| Official scenarios（orientation core） | 3：`macro-scan` · `personal-anchor` · `metacognition-audit`（已含 Phase A 交接补丁） |
| Official scenarios（handoff 层） | 3：`responsibility-scope` · `responsibility-bridge` · `analysis-closure` |
| Official references | 5：五学科理论卡片 |
| Community on disk | 物化自 Web 发现卡（scenarios + references） |
| **Machine catalog skillCount** | **92**（registry + MCP/CLI snapshot） |
| Bundle | `orientation-handoff` → scope → bridge → closure（见知识库 **13**） |

**Web 合并规则：**

1. `public/registry/catalog.json` → 可安装真相（`source: "catalog"` / installMode cli）  
2. UI overlay 可丰富 when/steps 展示字段  
3. **产品决策：** 网站可见 skill **必须** MCP/CLI 可装 → `pnpm catalog:sync-web` 物化 community  
4. 物化包是本地可装 skill 卡 + 上游链接，**不是**上游 git 完整镜像  

**载荷安装优先级（core）：**  
`OPENWISDOM_SKILLS_ROOT` → monorepo `skills/` → package `skills-snapshot/`

**常用命令：**

```bash
pnpm catalog:materialize   # Web seeds → skills/community/**
pnpm catalog:build         # 索引 + dual-write snapshot/registry
pnpm catalog:sync-web      # materialize + build
```

## 3. Monorepo 包图

```text
@openwisdom/schema      # zod frontmatter + catalog
@openwisdom/providers   # harness 路径表
@openwisdom/catalog     # build 脚本
@openwisdom/core        # install / catalog load / telemetry client
openwisdom (cli)        # citty + clack · 0.1.1
openwisdom-mcp          # MCP SDK stdio · 0.1.2
web                     # Next.js 16 App Router
```

Root scripts：`dev` · `build` · `test` · `catalog:build` · `catalog:sync-web` · `cli` · `mcp`
