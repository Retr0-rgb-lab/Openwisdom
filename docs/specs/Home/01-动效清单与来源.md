## 1. 动效技术栈（来源分层）

| 层 | 技术 | 在本仓库的位置 | 用途 |
|----|------|----------------|------|
| **引擎** | [`motion`](https://motion.dev/)（原 Framer Motion） | `import { motion } from "motion/react"` | 声明式入场、whileInView、状态切换 |
| **Chrome CSS** | [`tw-animate-css`](https://www.npmjs.com/package/tw-animate-css) + shadcn | `globals.css` `@import "tw-animate-css"` | 菜单/Sheet 等 chrome（非 Home 主叙事） |
| **品牌 Bits** | [React Bits](https://reactbits.dev/) **手动改编** | `apps/web/src/components/bits/*` | 背景/标题/聚光/跑马灯等 |
| **自研** | Openwisdom 产品逻辑 | `ClickSpark`、`SiteBackdrop`、`Model` 引用切换等 | 工具反馈、组装层 |
| **CSS 关键帧** | 组件内 `<style>` / `globals.css` | LogoLoop、ClickSpark、`.ow-view-enter` | 循环带、火花；view-timeline **未挂 Home** |

**安装方式（React Bits）：** 官方支持 copy-paste / `npx shadcn add @react-bits/...` / jsrepo。本仓库采用 **TS + Tailwind 手动拷贝改编** 进 `components/bits`，并改色为 Overlay Atlas（`--ow-primary` / `structure` / `signal` / `mist`）。

**许可注意：** React Bits 免费层为 **MIT + Commons Clause**（可商用进产品，不可把组件集当库再卖）。

## 4. Bits 组件 ↔ 上游映射

| 本仓库文件 | 上游 React Bits（文档名） | 官方文档入口 | 改编要点 |
|------------|---------------------------|--------------|----------|
| `DotField.tsx` | Dot Field | https://reactbits.dev/backgrounds/dot-field | 无光标凸起；色 = primary/structure/mist；RM 静态 |
| `Noise.tsx` | Noise（思路） | reactbits 动画/纹理类 | **仅静态 SVG**，禁每帧 canvas 噪点 |
| `BlurText.tsx` | Blur Text | https://reactbits.dev/text-animations/blur-text | 一次入场；CJK 按字；opacity 底 >0 |
| `LogoLoop.tsx` | Logo Loop | https://reactbits.dev/animations/logo-loop | ≥36s（现 40s）；hover 暂停；移动/RM 静态 |
| `SpotlightCard.tsx` | Spotlight Card | https://reactbits.dev/components/spotlight-card | radial ≤~14% alpha；主色+mist |
| `Reveal.tsx` | 对标 Fade Content / Animated Content | https://reactbits.dev/animations/fade-content 等 | whileInView once；opacity 底 0.22 |
| `Stagger.tsx` | 列表 stagger（Bits AnimatedList 同类） | 多库共有模式 | 子项 floor + y；与 Section Reveal 互斥 |
| `ClickSpark.tsx` | 无 1:1 上游；MAY 火花反馈 | — | 复制成功；主色/signal；RM 关 |

**禁止出现在 Home 的 Bits（Spec 08 NEVER，调研一致）：**  
Hyperspeed · Galaxy · Prism · Aurora · Beams · Lightning · Plasma · Ballpit · Splash/Blob/PixelTrail Cursor · Glitch/Decrypted 标题 · 假 CountUp 等。
