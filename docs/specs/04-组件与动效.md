## 1. 分工原则

| 层 | 职责 | 来源 |
|----|------|------|
| **设计系统 / 应用 chrome** | 导航、表单、卡片、对话框、侧栏、空状态 | **shadcn/ui** |
| **产品复合组件** | InstallCommand、SkillCard、SkillFilters、LocaleSwitcher | **自研**（组合 shadcn） |
| **品牌动效点缀** | Hero 入场、纹理、logo 循环、列表 stagger | **React Bits**（克制） |
| **长文排版** | Docs / skill 正文 | shadcn typeset 或 prose + Shiki |

**禁止：** 用 React Bits 当设计系统；用 shadcn dashboard 皮肤硬套营销首页。

## 2. 技术安装约定

### shadcn/ui

```bash
# apps/web
pnpm dlx shadcn@latest init   # Base UI / cssVariables / RSC
# 按需 add 组件
```

- Tailwind v4 + CSS 变量 → 映射方向 B token（铜 primary、冷 field）  
- `next-themes` 类策略 dark mode  
- 图标：lucide-react  

### React Bits

- 方式：`npx shadcn@latest add https://reactbits.dev/r/<Component>-TS-TW` 或文档拷贝  
- 变体：**TS + Tailwind**  
- 许可：MIT + Commons Clause（站内使用 OK；勿二次打包成竞品组件库出售）  
- **每页重组件 ≤2–3**；移动端可降级静态；尊重 `prefers-reduced-motion`

## 5. React Bits 选用矩阵

### Tier A — 建议采用

| 组件 | 位置 | 原因 |
|------|------|------|
| BlurText / SplitText | Hero H1（一次） | 清晰/洞察隐喻 |
| Fade Content / Animated Content | 区块入场、筛选结果 | 机构感 |
| Scroll Reveal / Gradual Blur | 长文/宣言 | 阅读站成熟度 |
| Noise | 全局极低透明度纹理 | 档案/印刷感 |
| Spotlight Card 或 Tilted Card | 技能卡 hover（二选一） | 深度，不炫技 |
| Animated List | 安装步骤、changelog | 功能动效 |
| Pill Nav / Staggered Menu | 顶栏 / 移动菜单 | 产品 chrome |
| Logo Loop | Harness 条 | 对标 Impeccable 信任条 |
| Count Up | 统计（skill 数等） | 可信指标 |
| Text Type | **仅**安装命令演示一次 | CLI 心智 |
| Silk **或** Threads **或** Dark Veil **或** Dot Field | **Hero 背景最多一个** | 织物/坐标隐喻 |

### Tier B — 场景可选

Magic Bento（能力马赛克）· Scroll Stack（三场景叙事）· True Focus（一句 thesis）· Magnet（主 CTA）· Folder（official/community 示意）· Stepper（贡献/安装向导）

### Tier C — 禁止（Openwisdom）

Decrypted/Glitch/Fuzzy/ASCII Text · Splash/Blob/Pixel Trail Cursor · Electric/Star Border · Galaxy/Hyperspeed/Aurora 彩虹 · Ballpit/Faulty Terminal · Gooey/Dock/Bubble Nav · 3D Dome/Lanyard/Model Viewer · 每页堆 >3 重特效

## 6. 页面动效配方

### Hero

```text
[Background: Silk|Threads|DarkVeil|DotField 其一，低透明，移动可静态]
  [Noise 3–5%]
  [Eyebrow 静态]
  [H1 BlurText 一次]
  [副文 Fade]
  [InstallCommand 静态为主；可选 Text Type 一次]
  [Logo Loop]
  [Count Up 可选]
```

### 目录卡

```text
SkillCard = shadcn Card 结构 + 可选 Spotlight/轻 Tilt
  入场：筛选稳定后 Animated List / Fade stagger
  reduced-motion：无 stagger
```

### 详情 / Docs

- 标题静态（可访问 + 分享）  
- TOC 轻动或不动  
- 安装块：Glass 仅可选用于命令面板，默认哑光 surface  

### 路由切换

- 内容区短 Fade（200–300ms）  
- **不用** Pixel Transition 全页  
- 切语言：只交叉淡入文案，不重跑 Hero 重动画

## 8. a11y 与 i18n

| 点 | 要求 |
|----|------|
| 焦点环 | 保留 ring token |
| 图标按钮 | sr-only 文案 |
| 对比度 | muted 字在 paper 场上过 WCAG |
| 动效 | 系统「减少动态效果」全关装饰 |
| 文案 | 所有 shadcn 可见字符串进 next-intl  
| CJK 字体 | Noto SC 加载与 fallback，控制 CLS |
