# v1 交付范围

> 用户选择：**C（内容像样）+ 网页成熟（骨架完善、功能完善、艺术风格优秀）**。  
> 对标体验：https://impeccable.style/（详见 `04`）。

## v1 必须交付

### 1. 开源仓库

- 清晰 monorepo 或等价目录结构（skills / cli / web / docs 边界在设计阶段敲定）  
- Skill 与 reference 的**编写规范**（模板、元数据、命名、official vs community）  
- `official/` 与 `community/` 分层  
- 贡献指南 + PR / Issue 模板  
- LICENSE、README（中英至少覆盖安装与贡献主路径）  

### 2. 官方内容（「内容像样」）

| 类型 | v1 要求 |
|------|---------|
| 场景 skill | **三个齐备**：宏观扫描（macro-scan）、个人锚点（personal-anchor）、元认知体检（metacognition-audit） |
| 学科 reference | **五个学科均有若干 official 卡片**（心理学、社会学、历史学、政治学、经济学）；数量在设计/实现计划中定量，原则是「每科都能支撑场景 skill 引用，而非空壳分类」 |
| community | 目录与规范就绪；可先为空或仅示例，不阻塞发布 |

每个场景 skill 应至少：

- 清晰触发说明（何时用）  
- 分步分析流程  
- 输出结构（便于用户保存与复盘）  
- 引用相关 reference 的方式  
- 元认知/偏见检查点（尤其元认知 skill 与其它 skill 的交叉要求）  

### 3. Openwisdom CLI

- `search` / `install` / `update` / `list`（命名以实现为准，能力对齐）  
- **交互式**选择要安装到的 coding agents（类 Impeccable）  
- 支持非交互参数（便于脚本：providers、scope 等）  
- 通过 npm（或同等主流分发）可 `npx openwisdom …` 使用（包名最终以注册名为准）  
- **不**包含模型 API 调用  

### 4. 成熟网页

**骨架完善（信息架构）**

- 落地叙事页（方案 C）  
- Skills 目录（列表/网格 + 筛选 + 搜索）  
- Skill / reference 详情页  
- 下载入口（zip/单包等形态在设计中定）  
- 安装说明（CLI 优先，兼 GitHub / 手动）  
- 贡献页  
- Docs（入门、规范、FAQ 至少有骨架）  
- Changelog 入口（可简）  
- 中 / 英 UI 切换  
- 页脚：GitHub、协议、社区链接  

**功能完善**

- 按层级（scenario / reference）、学科、语言、official|community 筛选  
- 搜索（名称、摘要、标签）  
- 详情页展示元数据、安装命令一键复制、下载  
- 响应式（桌面 + 移动可用）  
- 基础性能与可访问性（可读对比度、焦点、语义标题等达到「可公开自信展示」）  
- 与仓库内容同步策略明确（构建时读仓库 / CI 生成索引等，设计阶段定）  

**艺术风格优秀**

- 非「默认 AI 模板站」；有明确视觉 POV  
- 完成度对标 Impeccable 官网气质（排版、节奏、组件精致度），**视觉语言服务社科/智慧主题**，避免照搬 Impeccable 的 design-slop 叙事皮肤  
- 空状态、加载、错误态有设计，而非裸文本  

### 5. 分发与社区入口

- GitHub：浏览源码、Release/下载、PR 贡献  
- 网页：发现 + 下载 + 贡献引导  
- CLI：安装到本地 Agent  

### 6. 热度统计（第三档）

- 网页：**下载 zip** 计入安装热度；**复制命令**可记漏斗、默认不进主榜  
- CLI：`install` **成功写入后**匿名上报（可 `--no-telemetry` 关闭）  
- 目录/详情展示 **30d + 累计**；支持 `sort=popular`；默认排序仍为 featured  
- 轻量 API + KV/Redis 等旁路存储；**不写进** `SKILL.md`  
- Docs/FAQ：隐私与关闭说明  

产品与实现契约：知识库 [12-热度与遥测](./12-热度与遥测.md)。现状：[05-系统现状与实现地图](./05-系统现状与实现地图.md)。

## v1 明确不做

- 网页内 AI 对话分析、账号体系、收藏夹云同步  
- CLI 内置 LLM 推理  
- 网页直传 skill 文件的审核后台  
- 强制全库双语正文  
- 付费 Pro / 商业化闭环（可预留叙事，不进 v1 范围）  
- 用户级安装历史画像、强制联网才能安装

## 建议的验收清单（发布前自检）

- [ ] 陌生人 1 分钟内理解产品是什么  
- [ ] 一条命令能把官方场景 skill 装进至少 2 个不同 Agent  
- [ ] 三个场景 skill 在真实 Agent 中可被触发并跑通主流程  
- [ ] 五个学科 official reference 均可在目录中打开并被场景引用  
- [ ] 中英切换不破坏主路径  
- [ ] 贡献页能把人带到可提交的 PR 模板  
- [ ] 移动端可完成「找到 skill → 复制安装命令」  
- [ ] 视觉与动效达到「愿意转发官网」的主观标准（对标 impeccable.style 的完成度，非复制其业务）  

---

## 范围风险与拆分提示

v1 同时包含：**内容生产 + CLI 多 provider + 成熟双语官网**。  
实现阶段建议拆成可并行子系统（内容、CLI、Web、规范/CI），但**对外仍以「完整 v1」为发布门槛**，与用户选择的 C + 成熟网页一致。
