# 帖子 02 · 从个人漂浮 / 时代坐标 → Openwisdom

## 推荐标题

**漂着的时候，缺的是可安装的坐标系**

备选：

## 正文（约 420 字）

忙完一天仍觉得空，不一定是懒。更常见的是**漂**：卷也卷不动，躺又躺不平；道理都懂，却说不清自己在历史和社会里钉在哪一格。

一边是个人问题——职业、城市、方向，**「我」的锚点在哪**？  
一边是时代问题——信息很多，却缺一张图：激励是什么、约束在哪、叙事在讲什么；**当下落在历史坐标的哪一格**？  
两端若不对齐，自我提升像原地跑步，刷新闻像情绪搬运。

缺的往往不是再多鸡汤，而是**可复用的方法结构**：  
先写清位置（关系 / 阶段 / 约束），再拆外物（激励 / 约束 / 叙事），再检查自己的偏见与证据缺口。

这正是 **Openwisdom** 要做的事。

它是**开源的社会科学 Agent Skills 库**。官方三条场景 skill 直接对应上面两问：

· **personal-anchor** — 个人锚点：把我放进历史与社会坐标  
· **macro-scan** — 宏观扫描：结构化看局势与时代切片  
· **metacognition-audit** — 元认知体检：落地前审偏见与证据  

用法不是「打开网站和 AI 聊」——而是装进你已有的 Claude Code / Cursor 等，**在你自己的 Agent 里跑分析**。不托管聊天，不替你下结论。

官网：https://openwisdom.vercel.app  
可先装一个：`npx openwisdom install personal-anchor`  
或浏览后手动复制 skill 目录。

它是开源的，**也欢迎你一起补方法**：若你在自己的处境里总结出可复用的分析流程或理论卡片，欢迎 PR 到 `community/`，让更多人装进自己的 Agent 使用。贡献指南见官网 Contribute / 仓库说明。

**先钉住自己与时代，再决定往哪走——坐标系可以共建。**
