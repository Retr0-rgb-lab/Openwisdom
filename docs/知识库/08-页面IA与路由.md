# 页面 IA 与路由

> 蒸馏自原 Spec 03 / 10 / 30；实现以 `apps/web` 为准。

---

## 1. IA 原则

1. **双心智：** 落地页讲清「是什么、为何装」；Skills 是「图书馆」。  
2. **分层内容：** scenario + reference。  
3. **安装优先：** CLI 一命令主 CTA；网页下载 / GitHub 为辅。  
4. **分析在用户 Agent：** 站点不托管对话。  
5. **官方 / 社区：** 筛选与徽章清晰。  
6. **UI 双语 · 正文随贡献语言。**  
7. **热度可见：** 有 stats 才展示；默认 `featured`，可选 `popular`。

## 2. 站点地图

所有用户页：`/{locale}/…`，`locale ∈ {zh, en}`（**双前缀 always**；默认 zh）。

### 主路由

| 路由 | 角色 | 模式 |
|------|------|------|
| `/{locale}/` | 叙事首页 | Persuade |
| `/{locale}/skills` | Skills 目录 | Operate + Read |
| `/{locale}/skills/{slug}` | 详情（scenario 与 reference **统一**） | Operate + Read |
| `/{locale}/install` | 安装中枢 | Operate |
| `/{locale}/docs` | 文档 Hub | Read |
| `/{locale}/docs/getting-started` | 首次成功路径 | Read |
| `/{locale}/docs/concepts` | 场景 vs reference；运行边界 | Read |
| `/{locale}/docs/cli` | CLI 命令 | Read |
| `/{locale}/docs/agents` | Harness 路径 | Read |
| `/{locale}/docs/authoring` | 编写规范 → Contribute | Read |
| `/{locale}/docs/privacy` | 隐私与遥测 | Read |
| `/{locale}/docs/faq` | FAQ | Read |
| `/{locale}/docs/changelog` | 能力摘要 | Read |
| `/{locale}/contribute` | 贡献 → GitHub PR | Read |
| `/{locale}/about` | 使命与非目标 | Read |

### P1 / 可选

| 路由 | 角色 |
|------|------|
| `/{locale}/disciplines[/{id}]` | 五学科枢纽 |

### 不做

网页 AI 对话 · 账号/收藏 · 上传审核台 · 定价 · 博客（可后置）

### 机器端点

| 路由 | 角色 |
|------|------|
| `/registry/catalog.json` | 共用机器索引 |
| `/registry/manifest.json` | 构建 manifest |
| `/api/telemetry` · `/api/stats` | 热度旁路 |
| `/api/skills/[id]/download` | 下载 + 主热度计数 |

## 3. 全局导航

### Header

```text
[Logo Openwisdom]
  Skills | Install | Docs | Contribute
  [Search → /skills?q=] [中|EN] [GitHub]
```

### Docs 侧栏顺序

```text
Overview → Getting started → Concepts → CLI → Agents → Authoring → Privacy → FAQ → Changelog
```

## 4. Home：6-beat Persuade

原 9 模块裁为 **≤6 拍**（不含 header/footer）：

| 拍 | 模块 | 目的 |
|----|------|------|
| 1 | **Hero** | 60s 理解 + Install 主物件 + logo 方位语法 |
| 2 | **Harness** | 多 Agent 信任（静态或慢 LogoLoop） |
| 3 | **Scenarios** | 三官方 orientation 场景（非对称） |
| 4 | **Model** | 场景→reference + official/community 一屏 |
| 5 | **Disciplines**（可选短） | 五科入口或链 `/skills?discipline=` |
| 6 | **FinalCta** | 再一次 Install + GitHub |

**下沉子页：** InstallPaths → `/install`；ContributeTeaser → `/contribute`。

**漏斗：** Browse Skills 须真列表或诚实空态；场景卡链 `/skills/[slug]`。

## 5. Skills 目录（摘要）

| 项 | 规范 |
|----|------|
| 目的 | 发现 / 筛选 / 搜索 |
| URL | `?q=&layer=&source=&discipline=&lang=&sort=` |
| 排序 | 默认 `featured`；`popular` 仅有 heat 时 |
| 卡片 | title · layer · scope · disciplines · lang · summary · tags · heat? · 复制 install |
| 空态 | 清筛选 + 推荐 triad + 贡献说明 |

详见 [10-Skills-Web与数据契约](./10-Skills-Web与数据契约.md)。

---

## 6. Skills 详情（摘要）

- 统一 `/skills/{slug}`；`layer` 切换模块  
- 粘性安装条：`npx openwisdom install {slug}` · GitHub · Download  
- Scenario：When · Steps · Output · Bias · references  
- Reference：Definition · Bounds · Misuse · Questions · Used-by  

---

## 7. Install / Docs 职责切分

| 表面 | 负责 | 不抢 |
|------|------|------|
| `/install` | 命令密度、Harness 矩阵、验证步骤 | 不复制整页 Docs |
| `/docs` | 边界、首次成功、概念、隐私、FAQ | 不嵌套 Skills 目录；不 dump 内部 SPE |
| `/contribute` | PR 流程 | Authoring 链过来即可 |

Docs 视觉：Overlay Atlas × 冷静阅读壳；**无** DotField/BlurText；正文 ~65–75ch。

### Getting started 脊柱

安装路径 → 装 `macro-scan` → 在 **用户 Agent** 调用 → 校验 → 下一步 Concepts/FAQ/Skills。

### FAQ 必含

无网页聊天 · CLI/MCP 不调模型 · 文件装哪 · 更新 · UI 双语 vs 正文语言 · harness 看不到 skill · 热度/关闭（链 Privacy）。

---

## 8. 主用户旅程

1. **安装者：** Home → Install/CLI → Getting started → Agent 内 macro-scan  
2. **检索者：** Skills → 筛 → 详情 → 安装  
3. **贡献者：** Contribute → 规范 → GitHub PR → community  
4. **双语：** 切 locale；正文 `language` 徽章始终可见
