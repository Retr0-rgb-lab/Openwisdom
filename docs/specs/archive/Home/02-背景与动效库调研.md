## 2. React Bits 快照

| 项 | 内容 |
|----|------|
| 站点 | https://reactbits.dev/ |
| 源码 | https://github.com/DavidHDev/react-bits |
| 规模 | 宣称 **140+** 组件（Backgrounds / Text Animations / Animations / Components） |

| 组件 | 类 | 强度 | 冷静落地页？ | 本仓库 |

| **Dot Grid** | Backgrounds | 轻 | 是（低对比） | 未用 |
| **Shape Grid / Radar** | Backgrounds | 中 | 或可（仪器感，需降饱和） | 未用；与 DotField **互斥** Heavy |
| **Soft Aurora / Aurora / Beams** | Backgrounds | 中–重 | **否**（AI SaaS 默认） | NEVER |
| **Galaxy / Hyperspeed / Lightning / Plasma / Ballpit** | Backgrounds | 重 | **否** | NEVER |
| **Grainient / Noise 类** | Backgrounds/Anim | 轻 | 或可 | Noise 已用静态 |
| **Blur Text** | Text | 轻 | **是**（一次） | 已用 |
| **Split Text** | Text | 轻–中 | 短文可 | 未用 |
| **Text Type** | Text | 轻 | 仅 CLI demo | 未用 |
| **CountUp** | Text | 轻 | **仅真实数据** | 禁用假指标 |
| **Shiny / Gradient / Glitch / Decrypted Text** | Text | 中–重 | **否** | NEVER |
| **Fade / Animated Content** | Animations | 轻 | **是** | Reveal 对标 |
| **Logo Loop** | Animations | 轻–中 | **是**（真 harness 名） | 已用 |
| **Magnet** | Animations | 中 | 稀疏 CTA | 未用 MAY |

| **Animated List** | Components | 轻 | 步骤/列表 | 未用 MAY |

## 3. 竞品 / 邻域库

| 库 | 定位 | 许可 | 与 Next 16/R19/TW4 | AI 模板风险 |
|----|------|------|---------------------|-------------|
| **[Magic UI](https://magicui.design/)** | shadcn 向营销动效块 | MIT + Pro | 好（Motion+TW） | **高**（sparkles/aurora 整页搬） |
| **[Aceternity UI](https://ui.aceternity.com/)** | 电影感 beams/3D/parallax | 免费 copy + 付费 | 好 | **极高**（2024–26 AI 落地页脸） |
| **[Motion Primitives](https://motion-primitives.com/)** | 较小、克制的 motion 原语 | MIT + Pro | 好 | 中–低 |
| **[21st.dev](https://21st.dev/)** | 多库聚合 + agent 安装 | 随作者 | 发现用 | 高（无艺术指导生成） |
| **shadcn/ui** | 基础 UI | MIT | 基座 | 低 |
| **[Motion](https://motion.dev/)** | 动画引擎 | OSS | 核心依赖 | 中性（看用法） |
| **tw-animate-css** | CSS 工具反馈 | OSS | shadcn 路径 | 低 |
| **tsParticles** | 粒子背景 | MIT | 有 React 封装 | **极高** + 性能 |
| **Shader Gradient** | 流动 3D 渐变 | MIT | R3F 重 | 高（紫青网格英雄） |

### 对比一句话

| 库 | 一句话 |
|----|--------|
| React Bits | 特效目录最大；背景实验最多；**靠 allowlist** 才能不沦为玩具站 |
| Magic UI | 最贴 shadcn 工作流的营销微动效 |
| Aceternity | 「哇」密度最高，也是 AI 站同质化最高 |
| Motion Primitives | 默认更克制，适合补洞而非整站皮肤 |

**参考对比文：**  
https://www.pkgpulse.com/guides/react-bits-vs-aceternity-magic-ui-2026

## 4. 营销页动效实践（2025–26）

| 原则 | 对本站含义 |
|------|------------|
| **Heavy 预算** | 连续环境层 0–1；入场 one-shot ≤ ~600ms；本站已 3 Heavy 封顶 |
| **`prefers-reduced-motion`** | 关循环、关光标 FX、关 magnetic；保留信息 |
| **别用粒子英雄** | 与 Overlay Atlas 冷场、非 SaaS 定位冲突 |
| **scroll-driven vs once** | 优先 **进视口一次**；整页 scroll hijack 不适合 catalog 产品 |
| **真数据** | 禁止假 CountUp / 假 logo 墙 |
| **性能** | 全局 canvas 有成本；非 Home 可 static DotField |

**A11y 参考：**  
- https://web.dev/articles/prefers-reduced-motion  
- https://www.w3.org/WAI/WCAG22/Techniques/css/C39

## 5. 对 Openwisdom Home 的选型结论

| 决策 | 内容 |
|------|------|
| **主库** | React Bits **allowlist 改编**（现 bits/*）+ **motion** + **tw-animate-css** |
| **不引入为系统** | Aceternity / tsParticles / 默认 shadergradient 作为首页皮肤 |
| **可补洞** | Magic UI / Motion Primitives **单点**组件，且必须重色到 Overlay Atlas |
| **隐喻** | atlas / field / scan / structure — 非 magic orb / galaxy |
