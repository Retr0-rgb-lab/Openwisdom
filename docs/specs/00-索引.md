## 推荐决策（摘要）

| 议题 | 推荐 |
|------|------|
| 架构 | **方案 A：索引中心 monorepo**（pnpm + Turbo；`skills/` 真相源；`catalog.json` 供 Web+CLI） |
| 视觉 | **方向 B：Instrument of Orientation / 坐标图集**（冷场 + 铜色 datum + 衬线思辨） |
| 首页 IA | **方案 C**（叙事落地 + 主导航 Skills 目录） |
| UI 基座 | **shadcn/ui + Tailwind + Next.js App Router** |
| 动效 | **React Bits 克制点缀**；禁 neon/glitch/全屏 cursor 秀 |
| Docs | **Fumadocs headless** 或自建 Sidebar+MDX，同一 Next 应用 |
| 热度 | **第三档：网页下载 + CLI 安装成功**（匿名旁路 API；复制命令不进主榜） |
