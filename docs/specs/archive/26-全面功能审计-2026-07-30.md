# 全面功能审计 — 2026-07-30

> **类型：** 跨模块可用性 + Spec 符合性审计（只读验证，本文件为结论归档）  
> **方法：** 5 路并行 subagent（CLI / MCP / Catalog·Skills / Web Skills / Web Shell·Home·Install·Telemetry）+ 主会话 `pnpm test` / 各面 smoke  
> **权威对照：** `docs/specs/00-索引.md` 所列执行规格

   - CLI 装 Web 上多数 slug → **Skill not found**  
2. **GitHub / 远程 skill 载荷未实现**  
   - 仓外 `npx` 安装官方 skill 失败  
3. **官方学科 reference = 0**  
   - 分层模型与 v1「内容像样」未达标  
4. **npm 未发布 + package private**  
   - 站点文案诚实，但「功能完成」≠「用户可装」  
5. **Install hub / Docs / Contribute 实质内容缺失**  
   - Spec 03 P0 未闭合（install 重定向，其余占位）  
6. **Web 热度 API 全缺**  
   - Spec 06 网站验收未开始  

### P1 — 信任 / UX / 一致性

7. Bootstrap / curated **诚实横幅未挂载**  
8. **Source=community 语义失真**（curated-external 冒充 community）  
9. 官方详情不渲染磁盘 `SKILL.md` 全文  
10. MCP bundled 路径找不到 catalog-snapshot

12. Web **lint 失败**（GlobalSearch）  
13. 大量 external 卡仍带 `install.cli`（审计脚本 `CLI_INSTALL_FOR_EXTERNAL_ONLY`）  
14. `skills.bootstrap` / 部分 shell placeholder **死文案**  

### P2 — 抛光

15. Catalog 包无单测；filter/sort 无单测  
16. MCP list/update 缺专项单测
