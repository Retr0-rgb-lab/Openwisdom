## 1. Scope — 对象 / 边界 / 时间尺度 / 分析目标

- **对象**：单一行动者的职业流动决策，而非行业全景。
- **地理**：杭州（大厂） vs 深圳（初创）；两城的人才、资金、政策环境存在差异。
- **组织边界**：当前雇主（一线大厂的一个事业群 / 中台部门，性质假设为研发中台）、目标雇主（30 人以内 AIGC tooling 初创）、家庭与个人资产（未提供，省略）。
- **时间尺度**：决策窗口 ≈ 3 个月（offer 到期前）；影响期 3–7 年；评估期 10–15 年（职业生涯尾部）。
- **目标**：仅做结构映射（actors / incentives / constraints / trajectories），不给「该不该去」的结论。若需要决策体检，可另跑 `metacognition-audit`。

## 3. Structure — 关系 / 制度节点 / 否决点 / 资源流

### 3.1 制度节点与路径依赖（引用 `path-dependence`）

- **大厂路径锁定**：十二年累计产生的「特定技能 × 内部协调栈 × 团队声望」是**沉没资产**；离开会损失单位时间产出效率（重学外部技术生态 + 重建信用）。这里的「锁定强度」由 1) 既有协调人数（产品/运营/数据/算法协作半径）、2) 专用资产量（内部代号、特定中间件熟悉度）、3) 同行可观察记录 三项合成。当事人可量化的只有年限，专用资产的"可迁移性"未自评。
- **初创路径依赖反向风险**：30 人小厂若融资不顺，团队结构可能在 12 个月内重写两轮；股权的实际价值依赖多个非个人可控变量（下一轮估值、退出路径、回购条款）。这同样是一类 lock-in：把职业轨迹与公司命运绑死。
- **城市级路径依赖**：杭州的「互联网 + 制造业上下游」生态与深圳的「硬件 + 出海 + 跨境资本」生态，对可换工作集影响极大。换城不仅是搬家，是换职业「可调度的网络」。
- **路径依赖不取消能动**：声明见参考卡第 5 条——历史是约束，不是判决。早期事件（互联网红利期入行 + 长期留在大厂）解释了今天的处境，但不影响"今年是否切换"的策略空间。

### 3.2 否决点与集体行动（引用 `collective-action`）

- **个人层面的 veto**：配偶就业绑定、子女学龄、房贷剩余年限、医疗社保连续性、父母医疗半径——任一项升级为否决就足以终结讨论。资料未提供具体数据。
- **大厂层面的 veto**：HR 通常在 P 级通道的"P7→P8"或同档调整上有程序门槛，晋升评定不公开；两次"无晋升"若对应的是通道饱和而非个人绩效，那么无论做什么都难以短期改善。这是「环境 veto」，不是个人否决。
- **行业层面的 veto**：AIGC 赛道在 2026 年的资本/监管环境决定初创的可融空间。VC 风险偏好的逆转会让很多看起来"不错"的 offer 名义价值归零。这是不可观察、但必须入模的外部否决层。
- **搭便车问题（隐性）**：选择留在大厂是一种"安全搭便车"——继续享受组织提供的稳定与信用；选择离开是一种"动员成本个人化"——所有上行收益只属于本人。结构性后果是：当行业出现下行信号时，理性行动者倾向于选择前者，所以真正跳槽的人数被压制。

### 3.3 资源流

- **现金流**：当前（已知）稳定工资 + 已知股票 / 末位激励；初创（已知）低 base + 期权 + 可能签字费（若）。
- **时间流**：当前每周稳定 50±h；初创估算 70–80h，但有"上限未知"风险。
- **信号流**：从当前岗到大厂内 / 外网络的信号是双向稳定的；从初创向外的信号高度依赖 CEO 节奏，不稳定。

## 4. Trajectories — 情景 / 触发条件 / 否证信号

> 语气克制：不预设哪条是"正确路径"。每条轨迹附触发条件（A）与否证信号（F），用于事后回看而不用于当下结论。

### 4.1 轨迹 A：维持现状（默认惯性）

- **触发条件**：A1 个人出现住房 / 医疗 / 子女硬约束；A2 大厂近期出现架构重组、薪酬冻结或裁员传闻；A3 心理上"我可以再撑一年"。
- **否证信号**：F1 实际晋升通道仍关闭，且无任何被承诺的中长期兑现；F2 个人可观察的"可调出性"持续下降（猎头寒暄频次下降、推荐信语焉不详）。

### 4.2 轨迹 B：接受 offer

- **触发条件**：B1 拿到具体 vesting 表 + 4 年 cliff + 离场条款；B2 拿到签字费或过渡补贴以覆盖搬家 / 家庭安置；B3 对初创下一轮融资可见性有合理证据（例如已 close 或 strong term sheet）。
- **否证信号**：F1 vesting 写有"良好离开"条款（good-leaver）替换为"bad-leaver"，或公司无法在 12 个月内 close 下一轮；F2 团队中资历相近者一年内流失率 > 30%；F3 配偶/家庭出现反对的可观察行为。

### 4.3 轨迹 C：骑墙（拖延三到六个月）

- **触发条件**：C1 希望"先看清市场"，但缺乏具体信号源（无具体指标）；C2 大厂出现调薪或调岗机会的实际信号。
- **否证信号**：F1 offer 过期 / 政策变化 / 公司融资节奏改变；F2 个人决策疲劳开始损害当前岗的产出；F3 这一选项常常变成"长期不决定"，是机会成本最容易被低估的轨迹。

## 5. Gaps — 证据缺口 / 下一步可收集信息

按"决策权重"排序，未列出的项意味着默认按约束处理：

1. **家庭硬约束的具体值**：配偶是否可随迁、子女入学方案、父母医疗半径、当前房贷剩余与利率、未来 24 个月预期支出。这是最大的数据缺口。
2. **当前岗位的可替代性测试**：在 3–6 个月内主动面试 1–2 家同等量级公司，观察市场对该履历的回响。这是"路径依赖强度"的真正检验，不是靠自评可得的。
3. **初创的具体条款**：vesting、cliff、回购条款、下一轮融资可见性、CEO 留人历史（创始期是否换血）。
4. **行业层 veto**：2026 年中 AIGC tooling 赛道的资本情绪与监管边界，建议至少参考 1–2 个独立信息源，不靠单一新闻。
5. **健康与时间账**：个人的能量水平、是否处于照护期、睡眠质量——这类指标在主流决策框架中常被省略，但常常是实际否决项。

- C3：**该路径切换的实际转换成本是否被低估？** — 用 C：实际搬家 / 家庭安置 6 个月后的开支与可观察的精神成本。
