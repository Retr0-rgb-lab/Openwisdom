## 01 产品是什么 · EN

Openwisdom is an open-source social-science Agent Skills library (MIT).

Structured methods from psychology, sociology, history, political science, and economics—as installable skills for the coding agents you already use.

One library. Your harness. Your analysis.

→ https://openwisdom.vercel.app  
github.com/Retr0-rgb-lab/Openwisdom

## 02 如何工作 · EN

How Openwisdom works:

• Skills live as open SKILL.md packages in one library  
• You install them into Claude Code, Cursor, Codex, and similar harnesses  
• Scenario workflows cite discipline reference cards  
• Analysis runs in *your* agent, with *your* model  

Method + packaging, ready to plug in.

https://openwisdom.vercel.app

## 03 三场景 · EN

Three scenario skills, one library:

• macro-scan — structure situations & systems  
• personal-anchor — where *you* sit in social/historical coordinates  
• metacognition-audit — surface bias, blind spots, evidence gaps  

Scenarios cite discipline references. Install, then run inside your agent.

https://openwisdom.vercel.app  
github.com/Retr0-rgb-lab/Openwisdom

## 04 安装与贡献 · EN

Start with Openwisdom (MIT):

1. Browse → https://openwisdom.vercel.app  
2. Install → npx openwisdom install macro-scan  
3. Or wire MCP → npx -y openwisdom-mcp  
4. Invoke the skill in your agent  

Contribute: fork → write SKILL.md → open a PR.  
github.com/Retr0-rgb-lab/Openwisdom
